MyComponentOptions

@Immutable
data class MyComponentOptions(val button: MyComponentOptions.Button, val iconButton: MyComponentOptions.IconButton, val textField: MyComponentOptions.TextField, val checkbox: MyComponentOptions.Checkbox, val switch: MyComponentOptions.Switch, val dropdown: MyComponentOptions.Dropdown, val menu: MyComponentOptions.Menu)

enthält Optionen für Komponenten; Ziel ist es, dass Komponenten spezifisch (an MyThemeType angepasst) konfiguriert werden können

Defaults und Eigenschaften die der Nutzer nicht ändern können soll, werden in ComponentStyles definiert. Eigenschaften die der Nutzer ändern können soll, werden in MyComponentOptions definiert.
